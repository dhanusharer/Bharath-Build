# Failure Mode and Effects Analysis (FMEA) Catalog

**Document Version**: 1.0.0 (Phase 0 Freeze)  
**Standard**: Comprehensive System Failure Matrix with Explicit Detection, Mitigation, Logging, and Recovery  

---

| Failure Mode | Detection Mechanism | System Response (Backend) | User Response (UI & Audio) | Logging & Audit Requirement | Recovery Protocol |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Invalid Image Payload** | Magic bytes check fails; MIME type != jpeg/png/webp; file size > 10MB. | Immediate HTTP 400 Bad Request. Aborts pipeline before AWS calls. | Visual warning: "Please upload a valid JPEG, PNG, or WebP image under 10MB." | Log `request_id`, `client_ip`, `file_size`, and detected MIME type. | User uploads valid file format. |
| **Poor Image Quality (Blur/Dark)** | Laplacian variance < 100 or mean pixel luminance < 40. | Mark status `IMAGE_QUALITY_REJECTED`. Return HTTP 422. | Spoken + visual alert in selected language asking for bright, steady photo. | Log image quality metrics and `prescription_id`. | Prompt user to turn on room light and retake photo. |
| **Unreadable Handwriting** | Model returns `is_legible=false` on all medication items. | Fail-closed. Status `REQUIRES_HUMAN_REVIEW`. Return HTTP 422. | Spoken: "Doctor handwriting is unclear. Please consult pharmacist." | Record raw model extraction and flag `all_items_illegible`. | Direct user to in-person pharmacist review. |
| **Uncertain Drug Name** | Model confidence < 0.85 for `drug_name`. | Isolate item; mark `requires_review=true`. Prevent insertion into verified table. | Display item with amber badge: "Pharmacist verification needed." Spoken disclaimer. | Record unverified drug token and confidence score in `validation_results`. | Require manual pharmacist override or clear photo retake. |
| **Uncertain Dosage Value** | `strength_value = null` or ambiguous numeral pattern. | Fail safety gate for that item. Block dosage calculation. | Spoken: "Dosage quantity not decipherable. Do not guess." | Log `MISSING_DOSAGE_VALUE` violation for `prescription_id`. | Manual verification required. |
| **Uncertain Timing Shorthand** | Shorthand does not match approved regex (e.g., `1-?-1`). | Set `timing_uncertain=true`. All daily intake slots remain 0. | Voice omits timing and directs user to ask dispensing chemist. | Log unmapped shorthand string for review by data engineering. | Rule dictionary expansion if valid regional shorthand. |
| **Malformed AI Output** | JSON Schema validation exception (`pydantic.ValidationError`). | Abort processing. Status `EXTRACTION_FAILED`. Return HTTP 502. | Spoken: "Error processing document. Please retry shortly." | Log raw model output string, error stack trace, and prompt version. | Automatic retry with exponential backoff (max 1 retry); alert on-call. |
| **Bedrock API Timeout** | Request latency > 12.0s or AWS `ClientError` (504). | Terminate request. Circuit breaker increments failure count. Return HTTP 504. | Spoken: "AI server took too long to respond. Please try again." | Increment `bedrock_timeout_count` metric; log `request_id`. | User retries request. If circuit trips, fallback to standby model. |
| **Amazon Transcribe Failure** | STT API exception or confidence < 0.70. | Return HTTP 400. Invalidate voice intent. | Spoken: "Could not hear clearly. Please speak closer to microphone." | Log audio duration, sample rate, and transcription confidence score. | User re-speaks query. |
| **TTS Provider Failure** | Polly / regional adapter raises exception or timeout > 4.0s. | Render text cards in UI. Return HTTP 200 with `audio_available=false`. | Visual cards display text. UI shows button: "Retry Audio Playback". | Log `tts_provider_failure` with provider name and language code. | Fallback to secondary provider or mock audio generator. |
| **Database Connection Failure** | `asyncpg.PostgresConnectionError` or connection timeout. | Return HTTP 503 Service Unavailable. | Friendly error banner: "System temporarily unavailable." | High-severity CloudWatch alarm; alert operations team. | Database pool reconnects automatically; RDS failover if needed. |
| **Amazon S3 Outage** | S3 pre-signed upload or fetch fails with 500/503. | Return HTTP 503 Service Unavailable. | Error banner: "Storage service temporarily unreachable." | Log S3 error code, bucket name, and request correlation ID. | Retry S3 operation with exponential jitter. |
| **Unsupported Language** | User requests unmapped language code (e.g., `ta-IN`). | Return HTTP 400 Bad Request with supported list (`hi-IN`, `kn-IN`). | UI displays language selection dialog restricted to supported tongues. | Log requested unsupported language code for demand tracking. | User selects supported language. |
| **Duplicate Request** | Incoming request matches existing `Idempotency-Key`. | Return cached response without re-invoking Bedrock or Transcribe. | Seamless UI update; zero duplicate charge or processing latency. | Log `idempotency_cache_hit` with key and execution time. | Transparent cache return. |
