# Frontend Service - Multimodal Medication Accessibility System

Next.js 14 + TypeScript + Tailwind CSS assistive accessibility interface for digitizing handwritten prescriptions and providing voice-guided dosage schedules in Hindi and Kannada.

## Tech Stack
* **Framework**: Next.js 14 (App Router)
* **Language**: TypeScript (Strict Mode)
* **Styling**: Tailwind CSS
* **Icons**: Lucide React

## Getting Started

### Local Development
```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

### Build Production Bundle
```bash
npm run build
npm start
```

### Docker
```bash
docker build -t medication-accessibility-frontend .
docker run -p 3000:3000 medication-accessibility-frontend
```
